# سامانه جامع تحلیل و شبیه‌سازی مالی قرارداد بیمه - بانک (Bancassurance Simulator)

یک پلتفرم تحت وب توسعه‌یافته با **C# و .NET 8** برای مدل‌سازی، تحلیل اکچوئری، محاسبه نقطه سربه‌سر، ارزیابی سود و زیان (P&L) سه‌جانبه و تحلیل اثر تورم و ریسک فوت در مدل تلفیقی **بیمه عمر و پس‌انداز با تسهیلات بانکی (بانک & شرکت بیمه)**.

---

## 📌 ویژگی‌ها و قابلیت‌های کلیدی

1. **مدل‌سازی تراز افتتاحیه و گردش وجوه (Waterfall Analysis):**
   - تحلیل تسهیم ۱۰۰ میلیون تومان حق بیمه (۴۰ میلیون تومان نقدی بیمه‌گذار + ۶۰ میلیون تومان تسهیلات بانک).
   - اعمال کارمزد اولیه ۶.۵٪ بانک و سپرده مسدود ۴٪ به مدت ۱ سال با آزادسازی خودکار در ماه دوازدهم.
   - کسر ۵٪ هزینه بیمه‌گری، ۵٪ حق بیمه پوشش فوت و کارمزد نماینده.
   - محاسبه دقیق خالص واریزی اولیه به صندوق سرمایه‌گذاری با سود مرکب.

2. **تحلیل نقطه سربه‌سر (Breakeven Analysis):**
   - تعیین دقیق ماه و سال سربه‌سر شدن سرمایه‌گذاری نسبت به کل آورده نقدی و اقساط پرداختی.
   - محاسبه همزمان **نقطه سربه‌سر اسمی** و **نقطه سربه‌سر تعدیل‌شده با نرخ تورم (Real Breakeven)**.

3. **ارزیابی سود و زیان (P&L) سه ذی‌نفع:**
   - **بیمه‌گذار:** بازده کل، نرخ بازده داخلی سالانه (IRR)، ارزش بازخرید خالص و ارزش واقعی تنزیل‌شده.
   - **بانک:** کل سود دریافتی، کارمزد نقد، منفعت رسوب سپرده مسدود، بازده مؤثر (Effective APR) و ریسک اعتباری عملاً صفر.
   - **شرکت بیمه:** درآمد کارمزد بیمه‌گری، کارمزد مستمر مدیریت سبد، مازاد فنی فوت و حاشیه سود نهایی.

4. **ماژول اختصاصی تحلیل استراتژیک شرکت بیمه:**
   - ارزیابی پویا از مزایا، معایب و ریسک‌های قرارداد با تغییر هر نسبت و متغیر.
   - محاسبه نسبت کفایت وثیقه در سال اول و شناسایی ماه‌های دارای ریسک کسری وثیقه.
   - سیستم هشدارهای هوشمند اکچوئری (سن بالا، نرخ بازده منفی، کارمزد نامتعارف نماینده).
   - توصیه‌های سیاستی برای هیئت مدیره شرکت بیمه جهت عقد الحاقیه با بانک.

5. **شبیه‌سازی ریسک فوت و تسویه وام:**
   - جدول سناریوهای فوت در سال‌های مختلف؛ در صورت فوت، شرکت بیمه مکلف به پرداخت **سرمایه فوت + کل اندوخته** است و مانده وام با بانک تسویه شده و مازاد به وراث تعلق می‌گیرد.

6. **مدل‌سازی اثر تورم افسارگسیخته در ایران:**
   - مقایسه بلادرنگ ارزش اسمی اندوخته با ارزش روز و قدرت خرید واقعی با تورم‌های سالانه ۳۰٪ تا ۵۵٪.

7. **داشبورد تعاملی تحت وب:**
   - اسلایدرهای واکنش‌گرا و همگام با فیلدهای عددی با قابلیت محاسبه مجدد آنی (Debounced AJAX).
   - ۴ نمودار تعاملی جذاب با Chart.js.
   - سناریوهای آماده: استاندارد (تسهیلات ۲۳٪)، قرض‌الحسنه (۴٪)، تورم حاد (۵۵٪)، فروش مستقیم (بدون کارمزد).
   - خروجی اکسل / CSV از کل جدول گردش ماهانه.

## 🚀 پیش‌نیازها و راهنمای اجرا

### پیش‌نیاز:
- نصب [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### مراحل اجرا:
۱. رفتن به پوشه پروژه:
```bash
cd Bank_saman
```

۲. اجرای تست‌های خودکار:
```bash
dotnet test
```

۳. اجرای برنامه تحت وب:
```bash
dotnet run --project src/BancassuranceSim.Web/BancassuranceSim.Web.csproj
```

۴. باز کردن مرورگر و مشاهده برنامه:
```text
http://localhost:5177
```
